# Python Shopping Mall Management System

## Project Description
A Python-based Shopping Mall Management System with Admin and User functionalities.

## Features

### Admin
- Add new products
- Update existing products
- Remove products
- View available products
- View customer details and orders

### User
- View available products
- Add products to cart
- Remove products from cart
- View cart
- Calculate total bill
- Checkout and place orders

## Technologies Used
- Python

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code or IDLE.
3. Run shopping_mall.py.
